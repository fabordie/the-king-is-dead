The King is Dead

Seconde édition — le roi est mort, le royaume est divisé.

En ligne : un joueur crée la partie et communique le code à quatre lettres aux trois autres, qui ouvrent la même adresse et le saisissent. Chacun voit sa propre main ; le serveur arbitre les règles.
Un seul écran : les quatre joueurs jouent à tour de rôle sur le même appareil, avec un voile entre les tours pour préserver le secret des mains.
En équipes : les joueurs 1 & 3 affrontent les joueurs 2 & 4.
